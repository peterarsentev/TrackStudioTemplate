О чём этот поток

Многие разработчики умеют писать код, но не понимают, как устроен backend в реальной системе.

Backend разработка — это не только классы и методы. Это взаимодействие сервисов, базы данных, инфраструктура, деплой и работа системы в продакшене.

Этот поток показывает, как строятся backend-сервисы, которые можно реально использовать в production.

Что вы научитесь делать

  • проектировать API сервисов;
  • работать с базами данных;
  • строить backend-архитектуру;
  • разворачивать сервисы в инфраструктуре;
  • писать код, который можно поддерживать.

Основные темы потока

  • API
    REST, HTTP, контракты сервисов, структура backend-сервиса.
  • Базы данных
    PostgreSQL, проектирование схем, индексы и оптимизация запросов.
  • Работа с инфраструктурой
    Docker, CI/CD, деплой сервисов.
  • Интеграции сервисов
    очереди, взаимодействие между сервисами.
  • Практика разработки
    тесты, Git, code review, работа в команде.

Как проходит обучение

Обучение проходит в формате потока.

  • еженедельные модули;
  • практические задачи;
  • разработка backend-проекта;
  • проверка решений;
  • разбор на общих созвонах.

Каждая неделя — конкретный шаг в построении backend-системы.
